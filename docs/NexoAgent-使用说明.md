## 1. 产品概述

Nexo Agent 是一个集 **AI 对话**、**浏览器自动化**、**知识库管理**、**定时任务**和**工具编排**于一体的智能助手平台。它既可以作为独立桌面应用（Electron）运行，也提供 Web 控制台版本。

### 核心特性

| 特性 | 说明 |
| --- | --- |
| **AI 对话** | 支持多模型切换，多轮对话，工具调用 |
| **AI 浏览器** | 内置 Chromium 浏览器，AI 可直接操作网页 |
| **知识库** | 文档存储与语义检索，RAG 增强问答 |
| **记忆系统** | 长期记忆存储（daily / dream / script） |
| **定时任务** | Cron 定时触发 AI 任务 |
| **技能市场** | 可安装社区 Skill 扩展能力 |
| **通道管理** | 多模型 Provider 配置 |

### 技术架构

- **前端**: React + TypeScript + Ant Design
- **后端/Electron**: Node.js + Electron
- **AI 引擎**: 多模型支持（DeepSeek、Claude、Gemma、GPT 等）
- **数据存储**: SQLite（本地）

## 2. 快速开始

### 2.1 环境要求

- **Node.js** ≥ 18
- **npm** ≥ 9
- Windows 10+ / macOS 12+ / Linux（Electron 桌面应用）
- 现代浏览器（Web 控制台）

### 2.2 安装与启动

`ash
# 克隆项目
git clone <nexo-agent-repo>
cd NexoAgent

# 安装依赖
npm install

# 启动开发模式
npm run dev:electron    # 启动 Electron 桌面应用
npm run dev:web         # 启动 Web 控制台（默认 http://localhost:9898）
`

### 2.3 首次配置

启动后，在 **设置** 页面配置：

1. **模型 Provider** — 选择 AI 模型（DeepSeek / Claude / GPT 等）并填入 API Key
2. **Embedding 模型** — 配置向量化模型用于知识库检索
3. **语言偏好** — 选择中文/英文界面

## 4. AI 浏览器

> ⚠️ **AI 浏览器仅在 Electron 桌面应用中可用**，Web 控制台版本不包含此功能。

### 4.1 概述

AI 浏览器是 Nexo Agent 内置的共享浏览器会话，基于 Electron/Chromium 内核。它让 AI 能够**直接查看网页、操作 Web 应用、截图取证、执行自动化流程**，而你始终在同一个对话窗口内完成所有操作——不需要切换到外部浏览器。

![AI浏览器浏览百度](screenshots/02-browser-baidu.png)

### 4.2 浏览器控制栏

浏览器视图顶部提供标准导航控制：

| 控件 | 功能 |
| --- | --- |
| **后退 ←** | 返回上一页 |
| **前进 →** | 前进到下一页 |
| **刷新 ↻** | 重新加载当前页面 |
| **地址栏** | 输入 URL 后回车导航 |
| **跳转按钮** | 载入地址栏中的 URL |

### 4.3 缩放控制

浏览器视图右下角的浮动缩放面板支持 **50% ~ 250%** 的缩放范围，每次点击调整 10%。

### 4.4 交互方式

#### 方式一：对话指令（推荐）

在右侧对话面板直接用自然语言告诉 AI 你想做什么：

- *"打开百度并搜索 Nexo Agent"*
- *"进入 http://localhost:3003 并登录"*
- *"帮我截图当前页面"*
- *"打开 QQ 邮箱，发送一封邮件"*
- *"把这个页面上的表格数据提取出来"*

AI 会自动识别意图，调用 rowser_action 工具逐步执行。

#### 方式二：手动操作

你也可以直接在浏览器视图中手动点击、输入和浏览，如同使用普通浏览器。手动操作和 AI 操作**共享同一个浏览器会话**，状态保持一致。

### 4.6 DOM-first 目标解析

AI 浏览器采用 **DOM-first** 的元素定位策略——优先通过网页的**可访问性树（AX Tree）**和 DOM 信息来识别元素，而非依赖视觉截图。这让操作更稳定、更快速。

定位元素时 AI 可以使用：

- **元素文本** — 如 "提交" 按钮、"搜索" 输入框
- **角色** — button、textbox、link、checkbox 等
- **CSS 选择器 / XPath** — 精确定位
- **稳定引用 (ref)** — 快照返回的元素 ID，如 e1、e2

### 4.7 脚本模式（action="script"）

当普通点击和输入不够用时，可使用**脚本模式**。脚本运行在 Electron 服务进程侧（Node 环境），可以直接访问：

| 对象 | 用途 |
| --- | --- |
| rowserView | 浏览器视图对象 |
| webContents | 页面内容控制 |
| cdp / debugger | Chrome DevTools Protocol 原始接口 |
| scriptCache | 短期数据缓存 |
| equire | Node.js 标准模块 |

**适用场景**：抓包、注入脚本提取数据、CDP 原始事件、请求重放。

### 4.8 scriptCache 短期缓存

scriptCache 是脚本模式中的短期缓存，带 TTL 自动过期：

| 操作 | 说明 |
| --- | --- |
| set / get | 写入/读取缓存 |
| list / delete / clear | 管理缓存 |
| capture | 自动捕获脚本返回值 |
| consume | 读取后自动删除 |
| eplay | 重放缓存的请求 |

> ⚠️ scriptCache 仅在当前浏览器会话中有效。需要跨会话保留的流程应使用**脚本记忆**（Script Memory）。

### 4.9 使用技巧

1. **先 snapshot，再操作** — 不确定页面上有什么元素时，先让 AI 获取快照
2. **元素引用会过期** — 页面导航后之前的 ref 会失效，AI 自动重新获取
3. **手动和 AI 共用** — 手动浏览到某个页面后，再让 AI 分析或操作
4. **多步骤自动执行** — AI 会自动把复杂流程拆成多个 rowser_action 调用

### 4.10 典型场景

| 场景 | 说明 |
| --- | --- |
| Web 应用测试 | 自动登录、填表、验证功能 |
| 数据采集 | 从网页提取结构化数据 |
| 网页监控 | 定期检查网页变化并截图 |
| 邮件发送 | 操作 QQ 邮箱 / Gmail 等 |
| 后台操作 | 操作管理后台、配置系统 |
| 文档查阅 | 浏览在线文档、API 参考 |

### 4.11 限制与注意事项

- 纯 Canvas 绘制、跨域 iframe 内部和强反自动化页面可能需要特殊处理
- 脚本模式仅用于明确的浏览器运行时、CDP、抓包或调试场景
- 浏览器会话与当前对话绑定，切换会话后浏览器状态会重置
- 部分网站的验证码或人机验证需要用户手动协助

## 6. 知识库

### 6.1 功能概述

知识库用于存储和管理文档，支持**语义检索**，让 AI 能够基于你的知识库内容进行精准问答。底层使用向量数据库（Embedding）实现相似度匹配。

![知识库](screenshots/08-knowledge.png)

### 6.2 知识库操作

| 操作 | 说明 |
| --- | --- |
| **添加文档** | 上传 Markdown / TXT 文件或直接粘贴文本 |
| **编辑文档** | 在线编辑已存储的知识条目 |
| **删除文档** | 移除不需要的知识内容 |
| **检索测试** | 输入查询语句，测试召回效果 |

### 6.3 检索机制

- **语义检索** — 基于向量相似度的语义匹配（主策略）
- **关键词回退** — 语义检索效果不佳时自动回退到关键词匹配
- **混合检索** — 结合两种策略提升召回率

### 6.4 使用建议

- 将项目文档、FAQ、技术规范存入知识库
- 使用清晰的结构化标题，提升检索精度
- 定期更新知识内容，删除过时条目

## 7. 记忆系统

### 7.1 功能概述

Nexo Agent 提供三种类型的长期记忆，存储在本地 SQLite 数据库中：

![记忆面板](screenshots/07-memory.png)

### 7.2 记忆类型

| 类型 | 标识 | 用途 | 示例 |
| --- | --- | --- | --- |
| **Daily** | 日常记忆 | 每日工作记录、随笔记 | "今天完成了 API 文档" |
| **Dream** | 梦境记忆 | 创意记录、灵感碎片 | "梦到 SmartCare 生态系统" |
| **Script** | 脚本记忆 | 可复用的自动化流程 | "SmartCare 登录导航流程" |

### 7.3 Script Memory 详解

Script Memory 是最实用的记忆类型，用于**记录和复现自动化工作流**：

- **创建** — 完成一个流程后，让 AI "记住这个流程"
- **复用** — 下次说触发词即可自动执行
- **更新** — 流程变化时 AI 会更新同一条记忆

**示例 Script Memory：**

> **SmartCare 登录并进入故障分析页面**
> - 触发词: "进入故障分析"
> - 步骤: 导航 → 输入工号 → 输入密码 → 点击登录 → 导航到故障分析
> - 验证: URL 变为 /digital-factory/fault-analysis

### 7.4 记忆管理

- **查看** — 按类型筛选记忆列表
- **搜索** — 关键词检索记忆内容
- **删除** — 清理不需要的记忆

## 10. 定时任务

### 10.1 功能概述

定时任务允许你创建**定时触发的 AI 任务**，AI 会在指定时间自动执行预设的 Prompt。

![定时任务](screenshots/11-tasks.png)

### 10.2 创建任务

在对话中说：

- *"帮我定时 5 分钟后获取 GitHub 提交记录"*
- *"每天早上 9 点检查服务器状态"*
- *"每周五下午 5 点生成周报"*

AI 会自动解析时间并调用 create_scheduled_task 创建任务。

### 10.3 Cron 表达式参考

| 表达式 | 含义 |
| --- | --- |
|   9 * * * | 每天 9:00 |
|   9 * * 1-5 | 工作日 9:00 |
| */5 * * * * | 每 5 分钟 |
|   17 * * 5 | 每周五 17:00 |

### 10.4 任务管理

- **查看** — 任务列表中显示所有已创建的任务
- **启用/禁用** — 暂停不需要的任务
- **删除** — 清理过期任务
- **查看执行结果** — 每次执行生成对应的对话会话

## 14. 常见问题

### Q1: AI 浏览器标签在哪里？
**A**: AI 浏览器仅在 **Electron 桌面应用**中可用。Web 控制台版本（http://localhost:9898）不包含浏览器标签。请使用
